# EMU Cab 0.5.27 — CEE 1.1.4

## English

- Rebuilt CEE integration against public release `1.21.1-1.1.4`, replacing the old development-build requirement. CEE remains optional.
- Fixed connected shafts being destroyed by Create's speed-change protection during a VVVF motor ramp. A kinetic rebuild now counts its final speed change once, including CEE source reactivation.
- Preserves cab controls, dual cable backends, bogey audio, displays, balises and existing models/textures/sounds.
- Electrical and motor test runners now support isolated game directories and packaged-JAR testing.

Passed 21 core regression groups, real CEE/P&W/Sable electrical integration and VVVF motor server checks, including gradual acceleration/deceleration, immediate zero-command stop, power loss/restoration, legacy saved-state aliases and Sable assembly. All 90 existing assets/data resources are byte-for-byte unchanged from 0.5.26.

Replace the previous cab JAR with `emucab-0.5.27.jar` on client and server. For electrical features use CEE `1.21.1-1.1.4`; P&W integration should use P&W Sable Fix `1.5.2`.

## 中文

- 改用 CEE 公开发布版 `1.21.1-1.1.4` 编译电气兼容，修正旧开发版的依赖声明。CEE 仍为可选兼容。
- 修复渐变电机连续调速时，传动轴被 Create 频繁变速保护拆除的问题。动力网络重建期间只计入最终变速，兼顾 CEE 自身的动力源重新激活。
- 保留驾驶台控制、双线缆后端、转向架音效、显示屏、应答器及既有模型、贴图和音频。
- 电气与电机测试工具支持独立测试目录及实际打包 JAR。

已通过 21 组核心回归检查、真实 CEE/P&W/Sable 电气联动及渐变电机服务端测试，覆盖缓升缓降、零信号立即停转、断电恢复、旧存档别名和物理体装配。与 0.5.26 比较，90 项 assets/data 资源逐字节一致。

客户端和服务端用 `emucab-0.5.27.jar` 替换旧版。电气功能使用 CEE `1.21.1-1.1.4`；P&W 联动搭配 P&W Sable Fix `1.5.2`。

本轮未人工进入客户端实驾、试听或检查动画；服务端测试不代替完整整合包验证。
