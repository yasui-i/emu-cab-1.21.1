### 从源码构建

需要 JDK 21。先按 [本地依赖说明](libs/README.md) 准备 `libs/` 中的第三方 JAR，再运行 `./gradlew build`（Windows 使用 `./gradlew.bat build`）。完整回归检查：`./gradlew -I tools/check-controls.gradle checkCabControls`。当前产物为 `build/libs/emucab-0.5.26.jar`。首次构建需要联网下载 Gradle、NeoForge 和映射。

仓库包含源码及游戏所需的模型、贴图、音频等资源；不包含第三方依赖 JAR、运行存档、备份和 `model-source/` 建模草稿。部分历史制作工具引用本机外部文件和 `model-source/`，它们不是正常编译所需输入。GitHub Actions 运行不依赖 Minecraft 的核心逻辑检查；完整构建和21组回归检查需要准备本地依赖。许可保持项目元数据中的 All Rights Reserved。

相关 P&W / CEE 电气附属：[P&W Sable Fix](https://github.com/yasui-i/pw-sable-fix-1.21.1)。以下保留历史版本与开发记录，其中旧版本号及本机路径不代表当前安装要求。

# EMU Cab 0.5.15 — VVVF 转向架声音与电机迁移（2026-11-04）

客户端与服务端同时用 `emucab-0.5.15.jar`、`pwsablefix-1.4.1.jar` 替换对应旧版本。以下为本版行为；后续各版本章节保留为历史记录，安装版本、配置位置以本节为准。详细配置与验证范围见 [本轮使用说明](model-source/vvvf-audio-20261104/使用说明.md)。

已登记的 Simurail 转向架按真实轮面速度和模型轮半径换算 RPM，使用客户端实时 PCM 混合 PWM 电磁声、机械声和风噪。牵引负载来自测得的实际力；制动音色读取实际机械制动输入，用于声音模拟，不代表已增加再生回馈电路。音色采用通用模型，后续可调为具体车型。

制动缓解声的同一转向架冷却默认为5秒，可在 `emucab-common.toml` 的 `[simurail] brake_release_cooldown_seconds` 调大，最小5秒；冷却期间触发丢弃，不排队。网压/网流数值移至柱图下方空白处，原始显示贴图不变。

P&W Sable Fix 1.4.1 按最终选择使用 CEE 的②长电弧音源：实际触网播放约0.35秒，实际脱网播放约1.2秒，末尾分别用2/3 tick淡出；声音随 Sable 车体移动。无接触网的升降弓不播放，单独开关 VCB 不触发。直接引用 CEE 音源，不将其资产打入本模组。迁移后的独立电机本体继续复用 CEE 电机/风声音源变调；实时 PWM 混音用于已登记的 Simurail 物理转向架。

已通过构建、控制回归、真实 CEE 供电/转轴输出/旧 ID 迁移、Simurail 轮速遥测及客户端 PCM/Sable 声源验证。测试包含合成350 km/h位姿，未在用户完整列车线路实驾或人工评定听感。

## 0.5.8 调速器自定义步长

右键调速器打开界面，在“步长 RPM”输入每一级红石信号对应的目标转速，默认保留 17。目标转速为 `min(红石强度 × 步长, Create 服务端最大转速)`；红石强度只决定步数，不会按比例缩放 Create 上限。例如步长 20、输入 15，Create 上限 512 时目标为 300 RPM，上限 256 时为 256 RPM。只提高 Create 上限而不修改默认步长时，15 级仍对应 255 RPM。

界面显示当前服务端上限，直接读取 Create 的 `kinetics.maxRotationSpeed`。原有滚轮设置仍决定每变化 1 RPM 的时间间隔，非零降档缓降；输入为 0 立即归零。Create 生效上限降低时，超过上限的输出立即截断。步长逐方块保存，旧存档缺少设置时使用 17。网络包已更新，客户端与服务端需同时使用此版本。

## 修改模型后重新生成

1. 在 Blender 中修改并保存 `model-source/pixel-integration-20261101/驾驶台_A方案_无底座整合版.blend`。旧的 `model-source/reduced/jiashitai_edit.blend` 和有底座 A 整合版保留，导出器默认优先读取无底座 A 整合版。
2. Blender 后台执行 `tools/export_edited_cab.py`：读取已保存的 blend，导出网格和贴图，不保存或覆盖 blend。
3. 普通 Python（含 Pillow）执行 `tools/integrate_original_cab.py`：生成点击区、简化碰撞形状、静态分片和动态资源。
4. 运行上面的 Gradle build 命令。只修改模型后使用 F3+T 不会重新执行导出脚本。

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --factory-startup --disable-autoexec --python tools/export_edited_cab.py
python tools/integrate_original_cab.py
```

也可以在 Blender 命令末尾追加 `-- '其他源文件.blend'` 指定导出文件。
贴图按材质的 Base Color 图像分别导出，打包 PNG 保持原始字节；`source_name` 用于维持原控件编号。

按钮底座对照另存于 `model-source/button-base-comparison-20261101/驾驶台_按钮底座对照.blend`，
包含有底座和无底座两场景。无底座仅移除 16 个按压按钮最下方黑色底座，保留帽与银色边框并下移贴台面；
旋钮机构保留。对照 PNG 位于同目录；用户已选无底座，当前模组使用无底座版本。

`gen_models.py` 只执行第 3 步。旧 `reduce_original_cab.py` 是原始 OBJ 的首次减面工具，
检测到已有编辑版 blend 时会拒绝运行，防止覆盖用户修改。
